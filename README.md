# Postwoman

A free, native macOS app for running Postman collections through an embedded Newman. Everything is stored locally, nothing leaves your machine except the requests you send. It covers the basic Postman workflow, including scripting and response visualization. For advanced features and team collaboration, use Postman. No Node.js or Newman needed on the machine — both ship inside the app.

**English** · [Русский](#postwoman-ru)

## Features

- Import / export Postman collections (v2.1), folders, drag & drop, search
- Request editor: params, headers, body (raw / form-data / urlencoded / binary), pre-request and post-response scripts
- Collection / folder runner with CSV or JSON data files, iterations, interval, stop
- Variables live in Globals (secret ones are stored encrypted in the Keychain)
- Import a request from a cURL command, copy any request as cURL

## Requirements

macOS 15+, Apple Silicon (arm64), Xcode 16+ and [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

## Build

```bash
git clone https://github.com/<you>/Postwoman.git && cd Postwoman
bash scripts/update-runtime.sh   # downloads Newman + Node into Vendor/ (needs npm, once)
xcodegen generate          # creates Postwoman.xcodeproj
open Postwoman.xcodeproj      # or: bash scripts/build-app.sh
```

### The `Vendor/` folder

It is **not** in the repository (about 55 MB). `scripts/update-runtime.sh` creates it:

| File | What it is | Source |
|---|---|---|
| `newman-runtime.tgz` | Newman 6.2.3 + its pure-JS dependencies | npm package `newman` |
| `node-bin-darwin-arm64-<ver>.tgz` | official Node.js binary for macOS arm64, unmodified | npm package `node-bin-darwin-arm64` |
| `SHA512SUMS` | checksums, verified on every build | generated by the script |

Other versions: `NEWMAN_VERSION=6.2.3 NODE_VERSION=22.22.0 bash scripts/update-runtime.sh`.
You may also commit `Vendor/` to your own repo (files are under GitHub's 100 MB limit) — then the build works offline.

## Secret variables

Variables marked as secret are stored locally in encrypted form; the key is kept in the macOS Keychain and access requires authentication (Touch ID / password). Secret values are masked in the log and never written to disk in plain text.

For this to work, in Xcode open the target → **Signing & Capabilities** and enable **Automatically manage signing** (select your Team). Without a signing identity the Keychain is not available to the app.

## Distribution

An ad-hoc signed app is blocked by Gatekeeper on other Macs: `xattr -dr com.apple.quarantine Postwoman.app` or right-click → Open. For proper distribution use a Developer ID certificate and notarization (see `docs/DEVELOPMENT.ru.md`).

# Postwoman (RU)

Бесплатное нативное приложение для macOS , которое запускает коллекции Postman через встроенный Newman. Все данные хранятся локально, наружу уходят только отправляемые вами запросы. Реализованы базовые функции Postman, включая скрипты и визуализацию ответов. Для продвинутых функций и командной работы используйте Postman. Node.js и Newman на компьютере ставить не нужно — оба лежат внутри приложения.

## Возможности

- Импорт и экспорт коллекций Postman (v2.1), папки, перетаскивание, поиск
- Редактор запроса: параметры, заголовки, тело (raw / form-data / urlencoded / binary), pre-request и post-response скрипты
- Раннер коллекции или папки: файлы данных CSV / JSON, итерации, интервал, остановка
- Переменные хранятся в Globals (секретные — в зашифрованном виде)
- Импорт запроса из команды cURL, копирование любого запроса как cURL

## Требования

macOS 15+, Apple Silicon (arm64), Xcode 16+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

## Сборка

```bash
git clone https://github.com/<вы>/Postwoman.git && cd Postwoman
bash scripts/update-runtime.sh   # скачает Newman и Node в Vendor/ (нужен npm, один раз)
xcodegen generate          # создаст Postwoman.xcodeproj
open Postwoman.xcodeproj      # или: bash scripts/build-app.sh
```

### Папка `Vendor/`

В репозитории её **нет** (около 55 МБ), её создаёт `scripts/update-runtime.sh`:

| Файл | Что это | Откуда |
|---|---|---|
| `newman-runtime.tgz` | Newman 6.2.3 и его зависимости на чистом JS | npm-пакет `newman` |
| `node-bin-darwin-arm64-<версия>.tgz` | официальный Node.js для macOS arm64 без изменений | npm-пакет `node-bin-darwin-arm64` |
| `SHA512SUMS` | контрольные суммы, проверяются при каждой сборке | создаётся скриптом |

Другие версии: `NEWMAN_VERSION=6.2.3 NODE_VERSION=22.22.0 bash scripts/update-runtime.sh`.
Можно и закоммитить `Vendor/` в свой репозиторий (файлы меньше лимита GitHub в 100 МБ) — тогда сборка работает без сети.

## Секретные переменные

Переменные, помеченные как секретные, хранятся локально в зашифрованном виде; ключ лежит в Связке ключей macOS, доступ требует аутентификации (Touch ID / пароль). В журнале значения секретов скрыты, в открытом виде на диск они не пишутся.

Чтобы это работало, в Xcode откройте таргет → **Signing & Capabilities** и включите **Automatically manage signing** (выберите свою Team). Без подписи приложению недоступна Связка ключей.

## Раздача

Приложение с ad-hoc подписью на чужом Mac блокирует Gatekeeper: `xattr -dr com.apple.quarantine Postwoman.app` или правый клик → Открыть. Для нормальной раздачи нужны сертификат Developer ID и нотаризация (см. `docs/DEVELOPMENT.ru.md`).
